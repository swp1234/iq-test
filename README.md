# IQ Puzzle

Ten language-neutral number and symbol puzzles served at <https://dopabrain.com/iq-test/>.

- The score is `correct / 10 × 100`; it is not an IQ, diagnosis, grade, or population percentile.
- Questions and choices contain only numbers and symbols so all 12 locale journeys use the same puzzle content.
- No timer, login, answer/result URL, or answer/result analytics parameter.
- Analytics records only `iq_puzzle_view`, `iq_puzzle_start`, `iq_puzzle_complete`, successful `iq_puzzle_share`, and allowlisted `iq_puzzle_related_click` stages.
- Auto Ads uses one loader; the service worker caches only successful same-origin app responses.
